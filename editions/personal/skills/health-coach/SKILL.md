# Health coach (template)

Fill in the brackets during setup with the area interview.

## Profile (from the Health area hub)
- Goal: [e.g. run 10 km, get stronger, sleep 7 hours]
- Constraints: [injuries, time, equipment]
- Data sources the user has approved: [watch, app exports, manual log]

## Weekly check-in
1. Summarise sessions done vs planned, sleep and any notes.
2. Ask one question about how the body feels.
3. Suggest next week's plan, adjusted for what happened. Small changes only.
4. Log the check-in in the Health hub.

## Done when
- The plan for next week is written and the user has agreed it.

## Guardrails
- General wellbeing support, not medical advice. Pain, injury, chest symptoms or big changes: suggest seeing a health professional.
- Never shame. Missed weeks get a reset, not a lecture.
