# Personal edition

Sits on top of `core/`. Adds eight life areas and personal skills. Install core first, then copy these into your vault and skills library.

## Life areas

Each area is a hub note built from `core/vault-template/02 Areas/AREA-TEMPLATE.md` and filled in with the area interview (`core/skills/area-interview/SKILL.md`). Starter hubs are in `areas/`. Add each one as a row in `02 Areas/_index.md`.

| Area | Hub |
|---|---|
| Health | `areas/health.md` |
| Family and relationships | `areas/family.md` |
| Faith and meaning | `areas/faith.md` |
| Career and work | `areas/career.md` |
| Money | `areas/money.md` |
| Learning | `areas/learning.md` |
| Home | `areas/home.md` |
| Creative | `areas/creative.md` |

Skip any area that doesn't fit you. Rename freely.

## Skills

| Skill | What it does |
|---|---|
| `skills/journal` | Evening journal: mood, energy, wins, one lesson, quote of the day |
| `skills/morning-brief` | Calendar, weather, top three, open loops and watches in one short brief |
| `skills/health-coach` | Template: training plan, check-ins and gentle accountability (not medical advice) |
| `skills/study-partner` | Optional: tutor, flashcards, exam prep |
| `skills/work-partner` | Optional: your job and industry, news watch |
| `skills/money-manager` | Optional: budget, bills, goals, net worth (general information only) |
| `skills/investment-manager` | Optional: portfolio notes and thesis journal (general information only) |
| `skills/daily-interest-brief` | Optional: short daily brief on a sport, hobby or topic |

`drive-templates/money-tracker.csv` imports into Google Sheets for the money manager.
