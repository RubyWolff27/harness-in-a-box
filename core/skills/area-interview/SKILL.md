# Area interview

## Steps
1. Ask which area (or offer the list in 02 Areas/_index.md).
2. Ask up to six short questions, one at a time: why it matters, current state, goal for the next 90 days, what to remember, rules for helping, anything to watch.
3. Draft AREA.md from AREA-TEMPLATE.md using only the answers. Show it before saving.
4. On approval, save it and add or update the area's row in _index.md.
5. Offer one small first step (a checklist or a project note), not a full plan.

## Rules
- Never invent facts. Leave a section blank rather than guess.
- Keep private detail in the area note, never in shared or exported files.

## Done when
AREA.md saved, routing table updated, user has one next step.
