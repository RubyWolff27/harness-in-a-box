# Weekly review

The weekly review is where the harness learns. It turns a week of chats into updated memory, so next week starts from where you are, not from zero.

## When to use
- Once a week, same time (Friday afternoon or Sunday evening work well).
- Takes 20 to 30 minutes.

## What you need
- `open-loops.md`, `decisions-log.md`, `about-me.md` from my memory files.
- `telos.md` (goals, 90-day priorities, habits) and my master prompt.
- Last week's and next week's calendar (connector or pasted).
- My daily notes from the week, if I paste or share them.

## Steps
1. **Brief.** "Ideal state: I finish this review knowing my three priorities for next week, with nothing important lost, and my memory files up to date."
2. **Clear the decks.** Ask me to empty my capture inbox (the Inbox in my memory home, phone notes, Drive `0 Inbox`). For each item: action it, file it (PARA folder), turn it into an open loop, or delete it.
3. **Look back.** From last week's calendar and notes: what happened, what got done, what didn't. Ask me for one win and one thing that annoyed me.
4. **Open loops.** Go through `open-loops.md` one by one. For each: done, still open (with a next step and date), or dropped.
5. **Priorities and habits.** For each 90-day priority in `telos.md`: on track, behind or stuck, against its "done when". One line each. If stuck, suggest the smallest next step. Score this week's habits from my daily notes.
6. **Look forward.** Next week's calendar: anything that needs prep, travel, or a decision before it happens?
7. **Pick next week's three.** Three outcomes for the week, not tasks.
8. **Learn.** Ask: which skill helped most this week? Which did I not use? Is there a job I explained more than twice that should become a skill?
9. **Write the memory update block** (format below). Ask "Shall I apply this to my memory home?" If yes and the connector allows it, update each file and confirm what changed; otherwise I paste it.

## Never
- Never change calendars or emails. Update my memory home files only after I approve the memory update block; if you can't write to it, give me paste-ready text.
- Never put anything from my red-lines list into the memory update.

## Output: memory update block
```text
MEMORY UPDATE: week ending [date]

about-me.md (changes only):
- [line to add, change or remove, or "no change"]

telos.md (habit scores, priority status):
- ...

decisions-log.md (new entries, including board decisions):
- [date] | [decision] | [why] | [check on: date]

open-loops.md (full updated list):
- [ ] [loop] | next step: ... | by: [date]

Next week's three:
1. ...
2. ...
3. ...

Skills: [keep / tweak (how) / retire] for any skill discussed.
```

## Done when
- [ ] Every item in my capture inbox has a decision.
- [ ] Every open loop is marked done, open with a dated next step, or dropped.
- [ ] Each 90-day priority has a one-line status.
- [ ] Next week has exactly three outcomes.
- [ ] The memory update block is complete and has nothing from my red-lines list.
