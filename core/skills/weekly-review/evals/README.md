# evals for weekly-review

1. Two done loops, one stuck Now priority, empty Inbox.
2. Inbox with four items, Next week has a trip on Thursday.
3. Person says skip habits this week.

## A good answer must
- Clear every Inbox item with a decision
- Mark every open loop done, dated next step, or dropped
- Give exactly three outcomes for next week
- Produce a memory update block with nothing from red lines
- Wait for yes before applying
