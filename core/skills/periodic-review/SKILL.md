# Periodic review

Daily plans keep the day on track, weekly reviews keep the week on track. These keep **the life** on track.

## Monthly review (first weekend of the month, 30 minutes)
1. **Brief.** "Ideal state: I know how last month went on money, habits and goals, and my memory is clean."
2. **Money.** Run the money-manager monthly check-in (budget, bills, goals, net worth row).
3. **Habits.** From my daily notes, score each habit in `telos.md`: hit rate for the month. Which one to keep, adjust or drop?
4. **Goals pulse.** One line per goal: on track, behind or stuck.
5. **Memory clean-up.** Remind me to read my assistant's own memory (ChatGPT: Settings > Personalization > Memory; Claude: Settings > Memory; Grok Bot: ask it what it remembers) and delete anything wrong or sensitive. Suggest lines to archive from `open-loops.md`.
6. **Archive.** Finished projects to `04 Archive` (memory home and Drive).
7. **Memory update block** (format below).

## Quarterly review (every 3 months, 60 to 90 minutes)
1. **Rescore goals.** For each goal in `telos.md`, check every "done when". Score: done, on track, off track, drop. Evidence for each.
2. **Look back.** Biggest win, biggest lesson, what I'd do differently. Check decisions due for review in `decisions-log.md` and fill in "what happened".
3. **Board session.** "Convene the board" on the question: "What should my three 90-day priorities be?"
4. **Set the next 90 days.** Three priorities, each linked to a goal, each with a "done when".
5. **Mission check.** Does the mission still fit? Any area of life neglected?
6. **Skills audit.** Which skills did I use? Retire one, improve one.
7. **Memory update block.**

## Output: memory update block
```text
MEMORY UPDATE: [monthly/quarterly] review, [date]
telos.md: [goal scores, new 90-day priorities, habit changes]
about-me.md: [changes or "no change"]
decisions-log.md: [new entries; "what happened" for reviewed ones]
open-loops.md: [archived or added]
```

## Never
- Never change money or calendars. Change memory files only after I approve the update block; if you can't write, give me paste-ready text.
- Money and investing: general information only, not financial advice.

## Done when
- [ ] (Monthly) money, habits and memory clean-up all done.
- [ ] (Quarterly) every goal rescored with evidence; three new 90-day priorities with done-when checks.
- [ ] A memory update block was produced.
