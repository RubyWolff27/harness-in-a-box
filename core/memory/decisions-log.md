# Decisions log

Every decision worth remembering, in one line, with a date to check whether it worked. This is the "learn" step of the loop. Over a year it becomes one of the most useful files you own.

Newest at the top.

| Date | Decision | Why | Check on | What happened |
|---|---|---|---|---|
| YYYY-MM-DD | Example: Set up the personal harness with one assistant and a Google Drive memory home | One assistant with memory beats starting every chat from zero | YYYY-MM-DD (four weeks on) | |

## For bigger decisions

Use the Decision template (`vault-template/Templates/Decision.md`; as a Google Doc if your memory home is Drive) and link it from the table, for example `[[2026-11-02 Kitchen builder choice]]`.

Entries from the personal-board skill, newest at the top.

```text
## YYYY-MM-DD: [decision in one line]

```

## How to use it
- Add a line when you make a decision you might second-guess later.
- On the "check on" date, fill in "what happened" in a few words. Was it right? What would you do differently?
- The weekly review suggests new lines. You decide which ones go in.
