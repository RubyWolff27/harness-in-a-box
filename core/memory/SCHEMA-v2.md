# Memory schema v2

**One sentence:** An always-loaded Index (under about 400 words) points to on-demand sections; every line has a source tag and a date.

## Index (always loaded)

Keep under about 400 words. It lists who they are in one short block, the three Now priorities as one-liners, open-loop count, and pointers to the sections below. Do not paste whole sections into the Index.

## Sections (on demand)

| Section | Budget | Notes |
|---|---|---|
| About me | ~400 words | Identity, people (first names), style, red lines, interrupt rule |
| Now | ~200 words | Three 90-day priorities with done-when. **Expires after 90 days** unless the person renews in a weekly review |
| Open loops | ~40 lines | One loop per line |
| Decisions | ~30 rows | date, decision, why, review date |
| Inbox | ~20 lines | Newest first |
| Archive | unbounded file, not loaded daily | Old Now blocks and closed loops |

## Provenance (every line)

Tag each fact with source and date:

- `(said by me, YYYY-MM-DD)`
- `(from a document, YYYY-MM-DD)`
- `(inferred, YYYY-MM-DD)` - use sparingly; confirm next chat

## Archive rule

When Now expires, or Open loops / Decisions exceed budget, move the overflow into Archive with the date. Propose the move; apply only after a yes.

## Lite shape

Lite still uses one `My Harness` document. Put the Index at the top, then the section headings. Full lane may split sections into separate docs; the Index stays the always-loaded front door.
