# Why plain files

Your memory, skills and rules live in ordinary markdown files in a folder you own.

- **You can see it.** Open any file and read exactly what your assistant knows. Fix it by editing.
- **You can move it.** Claude, ChatGPT, Gemini, Grok Bot and open-source agents can all read a folder of text files. Switching tools means pointing the new one at the folder.
- **You decide what is remembered.** Built-in app memory chooses for you. Here, the assistant proposes updates and you keep the final say.
- **It has history.** Put the folder in Git or a synced drive with version history and every change can be undone.

Three levels of memory: global app memory for stable preferences, project memory for one workstream, and your own files when accuracy and control matter. This kit is level three.
