# Archetype A: chat-only

**One sentence:** You talk in a chat that forgets you between sessions and cannot schedule work.

## Capability defaults (Lite)

| Need | Default on A |
|---|---|
| Fetch the kit | Person uploads the ZIP or pastes each file |
| Built-in memory | Put identity, style and red lines at the top of `My Harness`; ask them to paste that section at the start of each chat |
| Memory home | Paste-ready `My Harness`; they save it |
| Playbooks | Keep under a **Playbooks** heading in `My Harness` |
| Routines | Give the two `lanes/LITE.md` L6 prompts and suggest phone alarms |
| Calendar | They paste tomorrow's day into the morning prompt |
| Safe mode | Tell them how to turn alarms off; treat any connector as read-only |

## Product overlay

If you know the product name, also read the matching file in `archetypes/overlays/`. Menu names live only in overlays. If unsure, ask: "Which app are you talking to me in?"

## Done when

You have told the person, in one line, that this is archetype A, and you are following these defaults.
