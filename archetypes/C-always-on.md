# Archetype C: always-on cloud computer

**One sentence:** You have your own cloud computer, so routines and file work can continue while their laptop is closed.

Examples: Grok Bot, ChatGPT dot, Muse.

## Capability defaults (Lite)

| Need | Default on C |
|---|---|
| Fetch the kit | Clone or download the ZIP to your computer, read-only |
| Memory home | Google Docs in `Harness` when Drive is connected; else files on your computer exported monthly |
| Playbooks | Private skills / Skills tab when available; always keep a Playbooks fallback in `My Harness` |
| Routines | Create and **test** both Lite routines; confirm the schedule UI |
| Approvals | Keep send, buy, post, delete behind ask / approval |
| Safe mode / storm | Pause every routine on this computer; connectors read-only |
