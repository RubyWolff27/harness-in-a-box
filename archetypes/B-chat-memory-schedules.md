# Archetype B: chat with memory and schedules

**One sentence:** You remember across chats and can run scheduled prompts, but you do not have your own always-on computer.

Examples: ChatGPT Plus Projects, Claude (paid), Gemini Tasks (when schedules work).

## Capability defaults (Lite)

| Need | Default on B |
|---|---|
| Fetch the kit | Raw URLs one at a time, or ZIP upload |
| Built-in memory | Save identity, style and red lines in the platform memory |
| Memory home | Google Doc `My Harness` if Drive/Docs connected; else paste-ready file in a Project |
| Playbooks | Platform skill store if available; else project files / Playbooks section in `My Harness` |
| Routines | Create the two `lanes/LITE.md` L6 prompts with risk contracts; confirm next run times |
| Calendar | Read-only connector after a yes |
| Safe mode | Pause every scheduled task; connectors read-only until they say otherwise |
