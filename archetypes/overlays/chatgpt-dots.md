# Overlay: ChatGPT dot

Status: **Beta**. Checked against: OpenAI Help Center, "Getting started with your dot" (20 Nov 2026) and "Scheduled tasks in ChatGPT", 21 Nov 2026. Archetype: **C**.

## Menu names (Lite)

| Step | Where |
|---|---|
| Access | Pro and selected Plus, aged 18+, outside EEA/UK/Switzerland (rolling out) |
| Memory | Dot's own saved memories (separate from ChatGPT memory settings) |
| Apps | Dot profile > Customize > Plugins |
| Routines | Dot profile > **Scheduled** |
| Approvals | Built-in safeguards plus custom rules |
| Safe mode | Pause every Scheduled item on the dot; connectors read-only |

## Known gaps

- Disconnecting an app does not delete what the dot already learned.
- Each task has its own conversation; corrections go in the affected task.
